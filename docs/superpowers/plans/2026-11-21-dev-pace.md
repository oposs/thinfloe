# Dev pace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Shorter feature rounds: one CI run per round, a shorter `local / image` job, faster local tests, fixtures that survive a new struct field, and a review loop with a fixed end.

**Architecture:** Two pull requests. PR 1 (branch `devpace-ci-dedup`, Task 1) removes the duplicate unit run from the image job and goes to `main` alone, so its runs give the baseline. PR 2 (branch `devpace-round`, made from `main` after PR 1 is merged, Tasks 2-8) adds a `PREBUILT=1` make mode, splits the smoke tests into parallel CI jobs, runs the Python unit tests in parallel, adds `make test-menu`, `..Default::default()` fixtures and the workflow rules in CLAUDE.md.

**Tech Stack:** GNU make, bash, Python 3 (stdlib only), GitHub Actions (reusable workflow `ci-local.yml`), Rust/cargo for the menu crate.

**Spec:** `docs/superpowers/specs/2026-11-21-dev-pace-design.md`

## Global Constraints

- At most 4 cores locally: `BUILD_JOBS`/`TEST_THREADS` default 4; cargo under `flock /scratch/oetiker/claude-tmp/thinfloe-cargo.lock systemd-run --user --scope -q -p MemoryMax=6G --`; image targets under `flock /scratch/oetiker/claude-tmp/dbrrg-build.lock make <t> VERSION=devpace`.
- No test is removed and no test checks less. Every smoke test and `test-runtime` still runs on every PR.
- `ci.yml` is not changed (repo-infra standard; `ci-passed` keeps `needs: [local, release-pr-current, release-verdict]`). `release-build-local.yml` is not changed.
- No CHANGES.md entry for any part. Both PRs need the `no-changelog` label (owner sets it).
- A smoke job never builds the `thinfloe-ubuntu` container and never exports the rootfs.
- Every GitHub-side action (push, PR, label, re-run, merge, branch delete) is owner-confirmed. Merges are rebase merges.
- Comments and docs in English, in the house style (repo-infra:writing-style).

## Review Focus

1. **A smoke job that silently rebuilds or runs on other bytes.** A smoke job must fail if any downloaded file changed or a `thinfloe-ubuntu` image appears. Test: Task 3, `scripts/ci-check-prebuilt.sh` and its test.
2. **`PREBUILT=1` with a file missing** must stop with make's "No rule to make target", not build it. Test: Task 2, `test-make-targets.sh` case "missing kernel".
3. **A smoke job's failure hidden from `ci-passed`** (a called workflow's job with `needs:`, or a matrix leg). Test: Task 4, the negative run.
4. **An empty or missing `test/unit`** must not pass the parallel runner vacuously (exit 2). Test: Task 5, `test_no_modules_is_an_error`.
5. **Two Python test modules sharing a fixed path** fail only when run at the same time. Test: Task 5, the suite run three times in a row with `-j 4`.

### Task 5: Parallel Python unit tests

**Files:**
- Create: `scripts/run-unit-tests.py`
- Create: `test/unit/test_unit_runner.py`
- Modify: `Makefile` `test-unit` (the `unittest discover` line)

**Interfaces:**
- Produces: `python3 scripts/run-unit-tests.py [-j N] DIR`. Runs `python3 -m unittest -v <module>` for each `DIR/test_*.py` (top level only, sorted), cwd `DIR`, environment passed through, at most N at once (`concurrent.futures`, default 4). As each module ends it prints `=== <file>: ok|FAIL (<s> s) ===` and then that module's whole output (stdout and stderr merged). Last line `unit: <n> modules, <k> failed[: <files>]`. Exit 0 if all pass, 1 if any failed, 2 if no module was found or DIR is not a directory.

  - `test_no_modules_is_an_error`: empty dir → rc 2; missing dir → rc 2.
  - `test_output_is_not_interleaved`: two modules that each print 200 numbered lines with sleeps → each module's lines are contiguous under its header.
  - `test_limit_is_respected`: `-j 2`, four modules that append start/stop times to a shared file → never more than 2 overlap.
