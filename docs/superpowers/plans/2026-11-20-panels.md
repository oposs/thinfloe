# Settings Info Panels Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Network, Screen and This machine tabs show their facts as labelled rows drawn by one helper, the info panel is at the top of Network and Screen, This machine shows all of them in two columns and copies them, and the Graphics band finds the GPU.

**Architecture:** `bounded::read_attr` reads sysfs attributes without trusting their reported size (the root cause of F). `infopanel.rs` holds the line model (`Line`, `Panel`), the drawing and the clipboard text. `nettab::info_lines`, `graphics::info_lines` and the machine rows produce lines; the three tabs draw them with `infopanel::draw`.

**Tech Stack:** Rust 1.96, egui 0.37, shadcn-egui (lyra), `src/thinfloe-menu`.

**Spec:** [docs/superpowers/specs/2026-11-20-panels-design.md](../specs/2026-11-20-panels-design.md).

### Task 2: the info panel helper

**Files:**
- Create: `src/thinfloe-menu/src/infopanel.rs`; Modify: `main.rs` (`mod infopanel;`), `brand.rs` (constants, literal-test list)

**Interface:**
```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Line {
    Group(String),
    Row { label: String, value: String },
    Note { text: String, warn: bool },
}
impl Line {
    pub fn row(label: &str, value: impl Into<String>) -> Line;
    pub fn note(text: impl Into<String>) -> Line;
    pub fn warn(text: impl Into<String>) -> Line;
}
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Panel { pub title: &'static str, pub lines: Vec<Line> }
/// The clipboard form: the title, its lines, a blank line between panels;
/// rows after a group indented by two spaces.
pub fn text(panels: &[Panel]) -> String;
/// The widest row label of `lines` in the body font, plus the item gap.
pub fn label_width(ui: &Ui, lines: &[Line]) -> f32;
/// The lines in a card's body: label in `foreground`, value muted and
/// truncated beside it; a group in `foreground`; a note muted or WARN.
pub fn draw(ui: &mut Ui, t: &Theme, lines: &[Line], label_w: f32);
/// A card band with `title` in `SECTION_PT` and the lines, `width` wide,
/// as the other Settings bands (`ROW_LEFT`, `ROW_RIGHT`, 12 top/bottom).
pub fn band(ui: &mut Ui, t: &Theme, width: f32, title: &str, lines: &[Line]);
```
`brand.rs`: `INFO_ROW_GAP: f32 = 2.0`, `INFO_GROUP_GAP: f32 = 6.0`, `INFO_COL_GAP: f32` (= `TILE_GAP`'s value), `INFO_TWO_COLUMNS_W: f32 = 900.0`.

- [ ] Step 1: Red tests for `text`: the spec's example verbatim; empty panel list is `""`; a panel with a note only; a group at the end of a panel stops the indent at the next panel.
- [ ] Step 2: Implement; add `("infopanel.rs", include_str!("infopanel.rs"))` to `ui_code_has_no_style_literals`. A render test (with the `ui.rs` test harness used by the band tests) that `band` draws the label and the value as separate texts.
- [ ] Step 3: Green, clippy, fmt. Commit `feat(menu): one info panel helper for labelled facts`.
