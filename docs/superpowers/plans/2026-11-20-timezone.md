# Time zone and NTP settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task (native: the brief forbids subagents). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Time band on Settings → Network that sets the system time zone and the NTP servers, shows the sync status, and makes chrony use the NTP servers DHCP sends.

**Architecture:** The menu stores `[time]` in `config.toml` and renders `generated/time`. The initramfs (`install_local_time`) installs it at boot; `sudo -n thinfloe-time apply` installs it live. `dhcp-timezone` respects a menu zone and feeds DHCP NTP servers to chrony. Status comes from non-root `chronyc -c` calls on the Network tab's poll.

**Tech Stack:** Rust (thinfloe-menu, egui + shadcn-egui, jiff), Python 3 (`thinfloe-time`), bash (`dhcp-timezone`), dracut shell (`thinfloe-lib.sh`), chrony.

**Spec:** `docs/superpowers/specs/2026-11-20-timezone-design.md`

## Global Constraints

- Cargo only as `flock /scratch/oetiker/claude-tmp/thinfloe-cargo.lock systemd-run --user --scope -q -p MemoryMax=6G -- env CARGO_BUILD_JOBS=4 cargo …` in `src/thinfloe-menu`; image targets only as `flock /scratch/oetiker/claude-tmp/dbrrg-build.lock make <target> VERSION=timezone`.
- UI colours from the theme, text sizes from named constants in `brand.rs`; `ui_code_has_no_style_literals` must stay green.
- Zone rule: a third column of `/usr/share/zoneinfo/zone.tab` or `UTC`.
- NTP rule: IPv4/IPv6 literal or host name (≤253 chars, labels 1-63 of `[A-Za-z0-9-]`, no leading/trailing `-`, no trailing dot); at most 8.
- `generated/time` format: header, then `zone=<z>` (0 or 1) and `ntp=<s>` (0 to 8) lines; absent when both automatic; mode 644.
- Root files: `/etc/thinfloe/time`, `/etc/localtime -> ../usr/share/zoneinfo/<z>`, `/etc/chrony/sources.d/thinfloe.sources`, `ubuntu-ntp-pools.sources` ↔ `ubuntu-ntp-pools.sources.thinfloe-off`, `/run/chrony-dhcp/thinfloe.sources`, `/run/thinfloe/state/dhcp-timezone`.
- No `exit` in a 90thinfloe hook; initramfs uses builtins plus `ln mv rm mkdir` only; `tf_log` to stderr.
- No new sudoers rule.
- Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- A menu zone set while a DHCP lease with `TIMEZONE=` renews: the menu zone must stay (Task 3 test `menu_zone_wins_over_a_renewal`).
- Switching from menu servers back to automatic: the pools file must be renamed back and DHCP servers rewritten (Task 2 test `back_to_automatic_restores_the_pools`, Task 3 restart path).
- A home restored from a stick whose `generated/time` names a zone missing from this image's `zone.tab` (tzdata changed): the boot goes on in automatic mode with a log line (Task 4 test `unknown_zone_is_skipped`).
- chronyd not running or slow: the status poll must not stall the tab (Task 5 test `chronyc_failure_gives_no_answer_line`, 2 s timeout).
- Typing in the NTP field and clicking the public IP switch in one frame: neither event lost (Task 6 test `ntp_field_and_switch_in_one_frame`).
