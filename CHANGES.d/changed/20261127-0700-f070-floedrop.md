- With no time zone set, FloeDrop takes the country from the keyboard layout (for example ch gives Switzerland), which allows the faster 5 GHz channel. If neither gives a country, Settings → Network says "No country set: set the time zone in the Time band below for faster FloeDrop."
- When the files in a phone's FloeDrop folder need more room than /media/tfuser/FloeDrop has left, they are no longer offered and stay in the folder; a note says "Could not send to …: not enough room in FloeDrop for … MB". A send that runs out of space on the way says the same.
- When a file in a phone's FloeDrop folder stays open for 30 seconds, a note says "Waiting to send to …: a file in its folder is still open"; the files go once it is closed.
- Settings → Network says "While FloeDrop is on, … is not used for Wi-Fi." for the card FloeDrop holds, and "owlyd did not answer at start; FloeDrop finds phones over mDNS only." when FloeDrop started without owlyd.
